This heritage viewer is a new service. We welcome your feedback to help
improve the experience.

### About This Service

This leverages technology from the [Arches](https://www.archesproject.org/)
community. **It is not an Arches instance itself, but is an automatic build
from exported Arches data.** It provides a simplified public interface for
exploring heritage information.

### Target Audience

Based on user research, the target audience for this service includes:

* General public interested in local heritage
* Visitors exploring heritage sites
* Researchers with high-level interest in specific assets
* Professionals doing quick lookups
* Media and educational organisations

### Providing Feedback

If you have feedback on this service, please use the contact information
provided in the footer.

When providing feedback, you might consider:

- Finding an asset that you are familiar with
- Finding assets near to a chosen location
- Sharing search results or individual asset pages
- Testing on both mobile and desktop devices

We are keen to receive feedback on usability across different devices and
use cases.
